# Synthetic demo templates

These fixtures are generated by `scripts/generate_fixtures.py` and are safe to
publish. They contain no government emblem, proprietary organization layout,
personal information, or confidential content.

- `sample_internal_memo.docx` includes A4 dimensions, margins, a header,
  footer, table, styled Thai text, signature block, and placeholders. The
  `{{body}}` placeholder is intentionally split across Word runs.
- `sample_price_comparison.xlsx` includes merged cells, formulas, borders,
  fixed row heights and column widths, freeze panes, and a print area.

Use them for the first local demo and for property-level preservation tests.
